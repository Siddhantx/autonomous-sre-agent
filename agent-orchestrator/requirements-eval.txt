# GenAI evaluation tier — a SEPARATE environment, by necessity not preference.
#
# DeepEval and this project's pinned telemetry stack cannot coexist. pip's
# resolver rejects the combination outright:
#
#   ERROR: Cannot install -r requirements-eval.txt and
#   opentelemetry-api==1.23.0 because these package versions have conflicting
#   dependencies. ResolutionImpossible
#
# DeepEval requires opentelemetry-sdk >= 1.44 and pydantic >= 2.11.7, while
# the agent pins otel 1.23.0 / pydantic 2.7.1. It also ships pytest plugins
# (xdist, rerunfailures, repeat) that would change collection for the main
# suite.
#
# So this file is self-contained rather than layered on requirements.txt, and
# deliberately leaves telemetry unpinned: the eval harness always runs with
# OTEL_ENABLED false, so the exporter is never exercised here. The agent's own
# pins are untouched and remain authoritative for production.
#
#   python -m venv .venv-eval
#   .venv-eval/Scripts/pip install -r requirements-eval.txt
#
# Nothing in the CI-gating path needs any of this. The deterministic metrics
# in evals/llm_eval/metrics.py run in the main environment, for free.
